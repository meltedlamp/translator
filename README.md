# Melted Talker

An Android app that detects the language you paste and turns it into English.

The page for it, with a short readme and the APK at the end, is [meltedlamp.github.io/translator](https://meltedlamp.github.io/translator/).

Download [To-English.apk](https://github.com/meltedlamp/translator/releases/download/v1.0.0/To-English.apk) (version 1.0). Open the file on an Android phone and allow the install. Paste text and tap Translate, or share text into the app from somewhere else. The words go to Google Translate. Nothing is saved on the phone.
